# Checkup 1.2.0

Checkup can now generate a local support bundle from a scheduled task without opening the desktop. Temporary-file inventory skips links, reports partial coverage, and has entry and time budgets. Existing command output is preserved.

## Verification

Engine regressions cover partial counts, missing roots, cancellation, cyclic junctions and exclusive exports. The self-contained EXE passed unattended report generation, existing-output protection and invalid argument checks locally.

Automatic setup and portable builds include the .NET runtime. Installers are unsigned. ZIP checksums verify downloaded bytes; they do not authenticate an unknown publisher.
